# نظام المدونة الذكية — عقد إيجار

## كيف تعمل المدونة
- كل مقال = ملف JSON في `content/blog/<slug>.json` (بدون سيرفر ولا قاعدة بيانات).
- الصفحات: `/blog` (القائمة) و`/blog/<slug>` (التفاصيل) — تُبنى تلقائيًا من الملفات عبر `features/blog/data/get-articles.ts`.
- شكل الملف (schema):
  ```json
  {
    "slug": "kebab-case-فريد",
    "title": "...",
    "categoryId": "property-management | contracts | real-estate-market",
    "date": "YYYY-MM-DD",
    "readTime": "٦ دقائق قراءة",
    "excerpt": "...",
    "coverImage": "/images/blog.jpg",
    "imageAlt": "...",
    "sections": [ { "type": "heading | paragraph | quote", "content": "..." } ],
    "sources": [ { "label": "...", "url": "..." } ]
  }
  ```

## إضافة مقال يدويًا
أضف ملف JSON جديدًا في `content/blog/` بنفس الشكل ثم ادفعه (git push) — يظهر في المدونة تلقائيًا.

## النشر التلقائي (يشتغل بدونك)
مهمة مجدولة **أسبوعية (الأحد)** تكتب مقالًا **مبنيًا على أرقام رسمية** (الهيئة العامة للعقار REGA / الإحصاء GASTAT / منصة إيجار) مع مصادر، وتنشره وتُرسل لك إشعارًا. لا تختلق الأرقام إطلاقًا.

### لتفعيلها تحتاج خطوتين:
1. **نشر الكود الحالي** إلى الموقع (حتى يصير `content/blog/` موجودًا في النسخة المنشورة).
2. تختار إحدى طريقتين للنشر التلقائي:
   - **ربط المهمة بجهازك** من تطبيق كلود على الكمبيوتر (Require this computer) — فتصل المهمة للمستودع وتدفع باستخدام صلاحيات git عندك. (تشتغل عندما يكون جهازك مفتوحًا.)
   - **أو أعطِني توكن GitHub** (repo-scoped) — وأحوّل المهمة لتعمل **بالكامل من السحابة بدون جهازك** (الأنسب لـ«تشتغل بدونك تمامًا»).

المهمة **معتمدة تلقائيًا** (auto-approve). حاليًا هي «مسلّحة» لكنها لا تنشر شيئًا حتى تُنجَز الخطوتان — وحتى ذلك الحين تتجاهل التشغيل بصمت بلا أخطاء.
